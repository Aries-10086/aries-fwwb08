0802 系统缺陷与优化总结
========================
整理日期：2026-07-22
项目：基于 AI 的数智党校学习系统（08）

一、功能缺陷 / Bug / 未完成（已修复 2026-07-23）
----------------------------
1. [已修复] 测验倒计时与服务端时限校验
   - 进入测验调用 /start 创建会话；前端倒计时，超时自动交卷；提交校验时长（含 60s 宽限）。

2. [已修复] 交卷校验测验状态与支部归属
   - 仅 published 且本支部可作答/交卷；草稿/关闭/跨支部拒绝。

3. [已修复] 测验作答次数限制与历史成绩
   - exams.max_attempts（默认 3）；列表展示已考次数、最高分与历史成绩。

4. [已修复] 「标记完成」刷新后保持
   - 从 GET /api/learning/progress 回读 isCompleted。

5. [已修复] 学习时长统计口径
   - 按 user+content 合并 upsert；离开页用 ref 避免重复/虚高。

6. [已修复] 学习进度查询接口
   - GET /api/learning/progress（可带 contentId）；首页展示已学/未学与任务进度。

7. [已修复] 学习任务编辑/删除与截止时间
   - PUT/DELETE /api/tasks；管理端/书记端支持编辑、删除、dueAt。

8. [已修复] 题库 / 试卷 / 测验删除
   - 对应 DELETE API + 管理端删除按钮（有引用时拒绝）。

9. [已修复] 视频内嵌播放
   - 支持 YouTube/Bilibili iframe 与直链 video 播放器。

10. [已修复] 党员端内容搜索
    - 学习首页搜索框调用 contents?q=。

11. [已修复] 支部书记任务发布 UI
    - 书记导航「任务」进入 /admin/tasks（限本支部）。

12. [已修复] 改密前端入口
    - /account/password；导航「改密」。

13. [已修复] 注册必须选择支部
    - 默认「请选择支部」；未选不可提交；后端仍校验 orgUnitId。

14. [已修复] 页面标题字色可读性
    - 管理/测验等页统一浅色主题 page-title 等样式。



二、安全问题（优先处理）—— 2026-07-22 已加固
--------------------------------------------
1. 【致命】伪鉴权可提权 —— 已修复
   - 现改为 HMAC 签名 access token（Authorization: Bearer）
   - 角色一律从数据库读取，忽略客户端 x-role / x-user-id

2. 部分敏感列表接口缺少登录校验 —— 已修复
   - users 仅管理员；org-units / contents / tasks / exams 需登录

3. 未登录时内容/任务过滤不严 —— 已修复
   - 未登录直接 401；非管理员任务强制按本支部过滤

4. AI 推荐/报告可指定任意 userId —— 已修复
   - 强制使用当前登录用户，忽略 body.userId

5. 上传文件目录匿名可访问 —— 已修复
   - 取消公开 /uploads 静态目录
   - 改为 /api/files/:name，需登录且校验内容访问权

6. 开放注册无审核、登录无防爆破 —— 已部分加固
   - 登录/注册增加 IP 限流
   - 可用环境变量 ALLOW_OPEN_REGISTER=0 关闭开放注册
   - 注册必须选择支部（禁止静默落到默认支部）

7. 演示弱口令与导入默认弱密码 —— 已部分加固
   - 导入禁止缺省 123456，密码必填且 ≥6 位
   - 演示账号仍保留便于评测（见 测试账号密码.txt）
   - 生产建议设置 AUTH_SECRET 并修改演示密码

8. CORS 全开、上传类型校验偏弱 —— 已加固
   - CORS 默认仅允许 localhost:5173
   - 去掉 zip；补充 MIME 校验


三、体验 / 产品缺口
--------------------
1. 「双端」实际是一套 Web 响应式，非独立移动端/小程序壳。
2. [已补] 书记「支部看板」：时长、任务/内容完成率、测验均分与党员明细（/m/dashboard）。
3. 任务列表看不到完成勾选/进度条。
4. 考试结果弱：错题回顾、历史成绩列表不足。
5. AI 自然语言查询对「今年」等时间语义解析不足。
6. 无个人中心（资料、改密、我的成绩、学习时长汇总）。
7. 党员综合评价「个人排名」不足，目前更偏支部均分排行。


四、技术债 / 性能 / 架构优化
----------------------------
1. 鉴权改为服务端会话或 JWT，角色从数据库读取，禁止客户端自报角色。
2. 组织统计、成员成绩存在 N+1 查询，数据量大时会变慢，宜批量聚合。
3. 学习记录改为按 (user_id, content_id) upsert，统一完成率与时长口径。
4. SQLite 缺外键约束，删组织/用户易留脏数据。
5. LLM 无配置时走 mock 文案，答辩前需接通真实国内大模型并写清说明。
6. shared/types 与实际字段不同步（如 username、attachments）。
7. 多处吞异常、服务端错误日志不足。
8. Vite 代理日志过吵，干扰开发排查。
9. SQLite 单文件适合演示，不适合高并发正式部署。
