# 基础功能测试用例

## 1. 登录与角色入口

### 用例 BF-001 一键登录

- 前置条件：系统已启动
- 步骤：
  1. 打开首页
  2. 点击“登录”
- 预期结果：
  - 直接进入管理后台
  - 页面无报错

### 用例 BF-002 高级角色切换

- 前置条件：处于登录页
- 步骤：
  1. 点击“切换身份（高级）”
  2. 分别点击党员、支部书记、系统管理员
- 预期结果：
  - 可进入对应角色界面

## 2. 组织架构管理

### 用例 BF-003 查看组织层级

- 步骤：
  1. 进入“组织架构”
- 预期结果：
  - 显示党委
  - 显示多个支部

### 用例 BF-004 查看支部统计数据

- 步骤：
  1. 进入“组织架构”
  2. 查看每个支部信息块
- 预期结果：
  - 成员数可见
  - 任务数可见
  - 完成率可见
  - 测验均分可见

### 用例 BF-005 新增支部

- 步骤：
  1. 输入组织名称
  2. 选择上级组织
  3. 点击“创建”
- 预期结果：
  - 列表新增对应组织

### 用例 BF-006 删除支部

- 步骤：
  1. 选择一个空支部
  2. 点击“删除”
- 预期结果：
  - 删除成功

## 3. 人员管理

### 用例 BF-007 新增人员

- 步骤：
  1. 填写姓名、角色、所属组织
  2. 点击“创建”
- 预期结果：
  - 列表新增该人员

### 用例 BF-008 编辑人员

- 步骤：
  1. 在人员列表点击“编辑”
  2. 修改姓名或角色
  3. 点击“保存”
- 预期结果：
  - 修改后信息正确显示

### 用例 BF-009 删除人员

- 步骤：
  1. 在人员列表点击“删除”
- 预期结果：
  - 普通人员可删除
  - 演示管理员不可删除

### 用例 BF-010 按姓名搜索

- 步骤：
  1. 输入姓名关键字
  2. 点击“搜索”
- 预期结果：
  - 列表仅显示匹配结果

### 用例 BF-011 按角色筛选

- 步骤：
  1. 选择角色
  2. 点击“搜索”
- 预期结果：
  - 列表仅显示所选角色

### 用例 BF-012 按支部筛选

- 步骤：
  1. 选择支部
  2. 点击“搜索”
- 预期结果：
  - 列表仅显示该支部人员
