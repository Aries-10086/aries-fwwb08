# 0802测试版

## 1. 测试目的

本文档用于对 `/Users/mac/Desktop/服务外包/08` 项目进行功能验证，重点覆盖：

- 基础功能闭环
- AI 功能入口可用性
- 新增补齐能力验证
- 导入功能验证

## 2. 测试环境

- 项目目录：`/Users/mac/Desktop/服务外包/08`
- 测试材料目录：`/Users/mac/Desktop/服务外包/08测试`
- 浏览器：Chrome / Edge 最新版
- 前端预览地址：以实际启动地址为准，例如 `http://localhost:4173/`

## 3. 启动步骤

1. 打开终端，进入项目目录：

```bash
cd /Users/mac/Desktop/服务外包/08
```

2. 启动前端预览：

```bash
npm run preview -- --host 0.0.0.0 --port 4173
```

3. 浏览器访问：

```text
http://localhost:4173/
```

4. 进入登录页，点击“登录”直接进入系统。

## 4. 测试执行顺序

建议按以下顺序执行：

1. 登录与入口验证
2. 组织架构管理
3. 人员管理
4. 学习内容管理
5. 题库管理
6. 数据统计
7. AI 功能
8. 导入能力验证

## 5. 详细测试步骤

### 5.1 登录页验证

步骤：

1. 访问首页。
2. 点击“登录”按钮。
3. 检查是否直接进入管理后台。
4. 退出后进入“切换身份（高级）”页，分别点击党员、支部书记、系统管理员。

预期结果：

- 一键登录可直接进入后台。
- 高级入口可按角色进入不同界面。
- 登录过程不出现 JSON 报错。

### 5.2 组织架构管理验证

步骤：

1. 进入“组织架构”页面。
2. 查看是否存在党委与支部层级。
3. 查看每个支部是否展示：
   - 成员数
   - 任务数
   - 完成率
   - 测验均分
4. 新建一个支部。
5. 删除一个无下级、无人员绑定的支部。

预期结果：

- 页面显示两级结构。
- 每个支部可见统计信息。
- 可创建支部。
- 删除受约束控制：有下级或有人员时应阻止删除。

### 5.3 人员管理验证

步骤：

1. 进入“人员管理”页面。
2. 使用姓名搜索。
3. 使用角色筛选。
4. 使用支部筛选。
5. 新增一名党员。
6. 选中已有人员，修改姓名或角色并保存。
7. 删除一名非演示管理员账号。

预期结果：

- 搜索和筛选结果正确。
- 新增成功后列表刷新可见。
- 编辑保存后数据正确更新。
- 删除成功后列表中不再显示该人员。
- `u_admin_demo` 不允许删除。

### 5.4 学习内容管理验证

步骤：

1. 进入“学习内容”页面。
2. 新建一条文章内容。
3. 修改标题、分类、标签、正文并保存。
4. 删除该内容。

预期结果：

- 内容可新增。
- 内容可编辑并保存。
- 删除成功后内容从列表消失。

### 5.5 题库管理验证

步骤：

1. 进入“题库管理”页面。
2. 新建一题。
3. 修改题型、分类、题干、答案并保存。
4. 通过批量导入面板导入测试题。

预期结果：

- 题目可新建。
- 题目可编辑保存。
- 导入成功后题目列表增加对应数据。

### 5.6 统计看板验证

步骤：

1. 进入“统计看板”页面。
2. 先查看“全部支部”统计。
3. 再切换到某个具体支部。
4. 对比成员规模、学习时长、测验均分、通过率是否变化。

预期结果：

- 看板可按支部筛选。
- 切换支部后图表与数值同步变化。

### 5.7 AI 功能验证

步骤：

1. 进入移动端首页，查看 AI 推荐模块。
2. 进入 AI 报告页面，查看是否生成评分、评语、建议。
3. 进入后台 AI 查询页面，输入：
   - 今年三支部学习完成率
   - 各支部测验平均分

预期结果：

- AI 推荐可返回推荐内容。
- AI 报告可展示评分与建议。
- AI 查询可返回文本和图表。

### 5.8 Excel / CSV 导入验证

步骤：

1. 打开“人员管理”页面。
2. 上传 `导入测试数据-人员.csv` 或自行另存为 `.xlsx` 后上传。
3. 点击“导入”。
4. 打开“题库管理”页面。
5. 上传 `导入测试数据-题库.csv` 或另存为 `.xlsx` 后上传。
6. 点击“执行导入”。

预期结果：

- 可正常读取 `.csv`
- 可正常读取 `.xlsx`
- 上传后文本框被自动填充
- 执行导入后新增数据可见
