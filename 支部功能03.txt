支部功能清单（书记端）
对照实现进度 · 2026-07-29

1. 本支部人员管理（受限版）

功能	说明	状态
查看本支部党员列表	只能看到自己支部的党员信息，不能看其他支部	[已完成] `/m/members`
查看本支部党员详情	查看学习进度、测验成绩等（用于督促）	[已完成] `/m/members/:userId`
不能：增删改党员	党员增删由系统管理员统一管理，书记只有查看权限	[已完成] 页面只读 + 用户写接口仅管理员
不能：跨支部操作	书记看不到其他支部的数据	[已完成] API 强制锁定本支部 orgUnitId

2. 学习任务发布（核心功能 ⭐）

功能	说明	状态
创建学习任务	为本支部党员派发学习任务，选择学习内容（文章/视频）	[已完成] `/admin/tasks`（书记可用，支部锁定）
设置截止时间	明确任务完成期限	[已完成]
编辑/删除任务	任务发布后可以修改或撤回	[已完成]
查看任务完成进度	看本支部有多少人完成了该任务，哪些人还没完成	[已完成] 任务页进度条 + 看板未完成名单
操作流程：选内容 → 选支部（默认自己支部）→ 设截止时间 → 发布	[已完成] 书记支部下拉锁定为本支部

3. 本支部数据统计（支部看板）

功能	说明	状态
学习时长统计	本支部党员的总学习时长、人均时长	[已完成] 总时长 + 人均时长
任务完成率	各学习任务的完成率	[已完成]
测验平均分	本支部党员的测验平均分	[已完成]
考试通过率	本支部党员的考试通过率	[已完成]
综合排行榜	本支部党员的综合学习排名	[已完成] `/m/scores` 综合排行榜；看板可跳转
注意：书记只能看到本支部的统计数据，看不到其他支部的对比（系统管理员才能看全局）。	[已完成]

4. 本支部测验/考试成绩查看

功能	说明	状态
查看本支部成绩	支部内所有党员的各次测验/考试成绩	[已完成] `/m/scores`「各次测验成绩」
查看未参与人员	谁还没参加测验，方便督促	[已完成] 按测验列出未参与名单
